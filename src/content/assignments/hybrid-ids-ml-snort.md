Design and evaluation of a hybrid IDS combining signature-based detection with Machine Learning. In a testbed generating realistic attack traffic (SYN scans, ICMP floods, stealth web probes), custom Snort rules provide accuracy while supervised (Random Forest, Logistic Regression) and unsupervised (Isolation Forest) models improve recall; a weighted risk-scoring fusion reaches an F1-score of 0.926.

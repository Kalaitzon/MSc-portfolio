A successful DNS spoofing attack using the Man-in-the-Middle technique with Ettercap on Kali Linux. Through ARP poisoning and the dns_spoof plugin, the victim's traffic was redirected from the legitimate DNS server to an attacker-controlled Apache web server and a forged page.

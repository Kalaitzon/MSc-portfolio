Penetration testing and reverse engineering of two vulnerable Android apps to recover hidden flags, using Apktool to decode configuration files (e.g. AndroidManifest.xml) and Android Studio for dynamic exploration. Reveals insecure local storage, recovering flags from SQLite Write-Ahead Log files and Shared Preferences XML stored in plain text.

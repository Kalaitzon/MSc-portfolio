A Defense-in-Depth architecture on Ubuntu Server combining iptables for port control and ModSecurity (WAF) for web-application protection. A strict policy permits traffic only on SSH, HTTP/S and port 9001; effectiveness against unauthorised connections and SQL injection was verified from Kali Linux.

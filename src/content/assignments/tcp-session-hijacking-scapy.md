A TCP session-hijacking attack in which the attacker interposes via ARP spoofing into an active Telnet session between a Windows 10 client and an Ubuntu server. By capturing SEQ/ACK numbers in Wireshark and forging a packet with Scapy, the attacker seizes the session and runs remote commands.

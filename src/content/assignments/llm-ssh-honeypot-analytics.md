Design and evaluation of an interactive SSH honeypot enriched with decoy artefacts generated by Large Language Models. A virtual filesystem and shell emulator run attack playbooks (reconnaissance, credential theft, lateral movement); sessions are clustered by engagement (K-means, Isolation Forest) and attacker intent classified (Random Forest), showing LLM-generated decoys are as convincing as manual ones while applying Responsible-AI isolation and data minimisation.

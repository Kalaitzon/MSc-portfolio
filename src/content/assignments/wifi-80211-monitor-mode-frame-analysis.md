Monitoring and analysis of wireless traffic at the Data Link Layer of IEEE 802.11. The wireless card is set to monitor mode on Kali Linux to capture raw frames, which are analysed in Wireshark to confirm the three frame categories (Management, Control, Data) via the Frame Control field, establishing the groundwork for active deauthentication attacks.

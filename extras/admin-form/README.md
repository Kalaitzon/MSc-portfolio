# Προαιρετική φόρμα προσθήκης εργασιών (τοπική)

Αυτή η φόρμα σου επιτρέπει να προσθέτεις εργασίες μέσα από μια σελίδα (ανεβάζεις PDF, γράφεις τίτλο κ.λπ.) αντί να φτιάχνεις `.md` αρχεία με το χέρι. **Δουλεύει μόνο τοπικά** (`npm run dev`) — ποτέ στο ανεβασμένο site.

Την έβγαλα από το βασικό project γιατί χρειάζεται έναν Node server, κάτι που περιπλέκει τη δωρεάν στατική φιλοξενία. Το βασικό site χωρίς αυτήν μένει καθαρά στατικό και ανεβαίνει παντού.

## Πώς την ενεργοποιείς

1. Εγκατέστησε τον Node adapter:
   ```powershell
   npx astro add node
   ```
2. Μετάφερε τα δύο αρχεία μέσα στο `src/pages/`:
   - `admin.astro`  →  `src/pages/admin.astro`
   - `api/`          →  `src/pages/api/`
3. Τρέξε `npm run dev` και άνοιξε **http://localhost:4321/admin**.

Όταν προσθέτεις εργασία, δημιουργείται αυτόματα το `.md` αρχείο και αποθηκεύεται το PDF στο `public/pdfs/`.

> Σημείωση: για δωρεάν στατικό ανέβασμα, μη μεταφέρεις αυτά τα αρχεία στο `src/pages/`. Χρησιμοποίησέ τα μόνο τοπικά και μετά κάνε ένα κανονικό `npm run build`.
